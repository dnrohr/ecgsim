# ECGSIM Research Archive

Collected from https://www.ecgsim.org/ on 2026-06-29 as source material for a modernized ECGSIM implementation.

## Contents

- `source/`: raw downloaded website files, preserving source host and path.
- `extracted-text/`: plain-text extraction of downloaded HTML/PHP pages for fast searching.
- `website-notes.md`: human notes from the website, manual, downloads, and references.
- `download_manifest.csv`: crawler manifest, including skipped app packages and external links.
- `source_checksums.csv`: SHA-256 checksums for every downloaded source file.

The Windows/Mac app packages and installers linked from the site were intentionally not downloaded.

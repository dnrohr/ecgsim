# Import And Export Compatibility

Status: task `0057` compatibility guide for implemented modern ECGSIM import/export workflows.

## Summary

| Workflow | Current support | Legacy ECGSIM compatibility | External-tool compatibility |
| --- | --- | --- | --- |
| Open `.ECGsimcase` in browser | Supported for bundled manifest cases only | Reads supported archived cases through generated bundles; arbitrary browser parsing is not implemented | Browser loads JSON bundles generated by project tools |
| Open generated case bundle in browser | Supported | Loads a user-selected modern bundle JSON that matches the viewer case-bundle contract | Same bundle schema emitted by `tools/export_viewer_fixtures.py` |
| Inspect `.ECGsimcase` metadata | Supported by Python CLI | Reads legacy case markers without modifying the file | Plain text CLI output |
| Read legacy matrix/vector/`.tri` files | Supported by Python readers | Supports documented ASCII formats plus selected binary variants | Useful for scripts/tests; MATLAB can read documented ASCII files |
| Export directory | Supported subset by Python CLI | Uses legacy-style folders and ASCII matrix/vector/`.tri` formats, but not full legacy `File -> Export` parity | Files read back through project readers; many are readable by MATLAB-style helpers |
| Source edit sidecar | Supported in browser | Modern-only; not a legacy `.ECGsimcase` or `.ECGsimsource` file | JSON sidecar with stable schema |
| Visual PNG export | Supported in browser | Modern equivalent to pane image capture, not legacy clipboard byte parity | Standard PNG files |
| Clipboard image copy | Best effort in browser | Modern browser clipboard behavior differs from legacy app lifetime semantics | Depends on browser/OS image clipboard support |
| Movie export | Unsupported | Legacy behavior still needs confirmation | None |

## Case Input

The browser viewer can open supported `.ECGsimcase` files by matching the selected file's SHA-256 and byte size against:

```text
app/viewer/public/fixtures/cases/manifest.json
```

The browser does not parse arbitrary `.ECGsimcase` binary data directly. To add a case to the browser, parse it with the Python package and regenerate viewer fixtures.

The browser can also open a generated case-bundle `.json` directly with the Open bundle control. This bypasses the hash allowlist but still validates that the JSON contains the required normalized bundle sections before replacing the current view.

Metadata inspection works directly on legacy case files:

```powershell
python -m ecgsim.cli.case_info research/source/www.ecgsim.org/downloads/cases/normal_male2.ECGsimcase
```

This command reads marker inventory and known metadata only. It does not modify the case file.

## Legacy Format Readers

The Python package reads:

- Legacy ASCII matrix files with `rows columns` headers.
- Legacy one-column ASCII vectors.
- Legacy ASCII `.tri` geometry files with one-based triangle indices.
- Selected binary matrix and geometry variants documented in `docs/file-formats/export-formats.md`.
- Known `.ECGsimcase` matrix, vector, geometry, source, lead-system, and signal metadata payloads.

Use the project readers for automated checks before assuming a file is compatible with the modern app.

## Export Directory CLI

Run:

```powershell
python -m ecgsim.cli.export_case research/source/www.ecgsim.org/downloads/cases/normal_male2.ECGsimcase scratch/normal-export
```

Installed environments also provide:

```powershell
ecgsim-export-case <case-file> <output-dir>
```

The writer emits a supported subset:

- `model/ventricle.tri`
- `model/thorax.tri`
- `model/rlung.tri`
- `model/llung.tri`
- `ventricular_beats/beat1/user.*` source-parameter vectors when available
- `atrial_beats/beat1/user.*` source-parameter vectors when non-empty vectors are available
- `ecgs/thorax.refECG`
- `metadata.json`

The emitted `.tri`, matrix, and vector files use documented legacy ASCII formats. Regression tests verify that the exported files can be read back by the project readers and preserve representative parsed values.

This is not a complete legacy `File -> Export` clone. Raw legacy export directories from the Windows app are still missing, so exact optional members, file naming, and value parity cannot be claimed.

Known missing export-directory members include:

- Model adjacency, distance, anisotropy, transfer, and lead transfer matrices.
- Electrode `.elec` files.
- Adapted ECG recomputation output.
- TMP waveform `.user.source` matrices.
- Activation/focus export files.
- Raw display/layout state.

## MATLAB And `readECGsim.m`

The modern export directory follows legacy-style folder names and ASCII data formats where implemented. However, `research/source/www.ecgsim.org/downloads/readECGsim.m` expects many files that the current writer does not emit yet, especially model transfer matrices and electrode files.

Use current exports as partial data products for geometry, parsed source vectors, and the parsed thorax surface-potential matrix. Do not expect `readECGsim.m` to load the directory as a full ECGSIM export until the missing members are implemented or stubbed with confirmed semantics.

## Source Edit Sidecars

The browser supports a modern JSON sidecar:

```text
<case>.source-edits.json
```

The schema is:

```text
org.ecgsim.source-edits
```

Sidecars store adapted TMP parameter vectors plus undo/redo transaction stacks. Import validates:

- Schema and version.
- Case SHA-256 when available.
- Source node count.
- Adapted vector lengths for every known parameter.

Sidecars are the chosen safe persistence path for now. Legacy `.ECGsimcase` write-back and `.ECGsimsource` compatibility are not implemented.

## Visual Exports

The browser can export current PNG frames for:

- Heart.
- Thorax.
- TMP.
- Leads.

Filenames use:

```text
<case-base>-<pane>.png
```

The Copy buttons attempt browser image clipboard writes. If browser or OS permissions do not allow image clipboard access, use PNG download instead.

Movie export is not implemented.

## Compatibility Rules For Contributors

- Do not claim full legacy export parity from the first normal male ECGSIM 3.0.1 capture alone; add focused comparisons against promoted raw export evidence for each supported workflow.
- Keep exported unsupported members visible in `metadata.json` and docs.
- Prefer sidecar persistence over modifying `.ECGsimcase` files until write-back semantics are proven.
- Add round-trip tests for every new import/export file type.
- Document units, index bases, and sample-rate assumptions next to the implementation.
